# Smart Adaptive Learning Platform

A full-stack programming quiz application with database-backed questions, an adaptive difficulty engine, topic-wise performance analytics, and personalized study recommendations.

## Stack

- Frontend: React + Vite
- Backend: Node.js + Express
- Database: MongoDB + Mongoose
